# 合同评审

对照红线和评审清单逐条检查合同，在有问题的条款上批注问题和修改建议。

## 评审清单

| 文件 | 内容 | 何时使用 |
|---|---|---|
| `references/redlines.md` | 红线（RL-xx） | 每份合同 |
| `references/checklists/通用-基础法务.md` | 主体、标的、价款、付款、发票、交付、违约、管辖、文本质量（GEN-xx） | 每份合同 |
| `references/checklists/立场-甲方乙方.md` | 我方为卖方/出租方/乙方，或买方/承租方/甲方时的侧重点（ROLE-xx） | 每份合同，用对应一节 |
| `references/checklists/通用-出口与国际业务.md` | 基础信息、价格保费、付款与信用证、中信保、交货单据、技术指导（EXP-xx） | 有境外主体、跨境付款或出口 |
| `references/checklists/铝模销售.md` | LMS-xx | 铝模新板/旧板/标准板/配件/型材销售 |
| `references/checklists/铝模租赁.md` | LMZ-xx | 铝模租赁、翻新租赁、暂出复进 |
| `references/checklists/爬架.md` | PJ-xx | 爬架/附着式升降脚手架销售、租赁、分包 |
| `references/checklists/贸易类销售.md` | TRD-xx | 外购产品转售出口（塑料模板、雾炮机、钢管等） |
| `references/checklists/增补单-补充协议.md` | SUP-xx | 增补单、补充协议、变更协议 |
| `references/trade-compliance-notes.md` | HS 编码、出口退税、目的国关税、Form E、指定查询站点 | 涉及出口 |

清单标记：〔比对〕需用报价单、分析报告、用量表等内部资料比对；〔补充〕依行业惯例补充，不来自公司原评审资料。

一份合同同时属于多种类型（如销售合同里带回购或租赁条款）时，对应清单都要用。不属于以上任何类型的，只用红线、通用法务和立场清单。

## 评审立场

- 默认站在志特（GETO）关联主体一方。以“志特”“GETO”及地域、法人后缀为线索，结合注册地、地址、注册号、合同角色确定具体主体（湖南志特、江西志特/江志、马来西亚志特/马志、新加坡志特等分别识别）。双方都是志特关联主体且无法判断代表哪方时，先向用户确认。
- 按实际权利义务判断我方是供给方（卖方/出租方/乙方）还是需求方（买方/承租方/甲方），不按“甲方/乙方”称谓判断。同一条款对两方利弊相反，红线和立场清单都要按这个角色套用。

## 评审步骤

1. **读合同定性**：确定我方签约主体、我方角色、合同类型、是否涉外、适用法律和争议解决方式。这些信息从合同中读取，不重复问用户；合同没写且本身构成风险的，作为问题批注。
2. **选清单**：红线 + 通用法务 + 立场清单对应一节；涉外加出口与国际业务清单和外贸合规参考；再按类型加对应清单。
3. **过红线**：逐条对照 `redlines.md`，注意每条的适用立场。
4. **过清单**：按选定清单逐条检查。已妥善约定的不批注；有问题或缺失的批注。
5. **补查**：清单没覆盖的问题，按四个维度补查——商业与履约风险、外贸与跨境合规、法律时效与可执行性、文本与文件质量。
6. **外部核实**：税率、退税率、关税、反倾销、法规现行效力、主体资信等时效敏感事项联网核实。`trade-compliance-notes.md` 列出的指定站点必须直接打开取得结果，搜索摘要和转载不能替代；查不到写“未完成现场核验”，不得写“已核实”。
7. **〔比对〕项**：有内部资料就逐项比对；没有的，在总评中列为待比对事项，不逐条批注。

用户只要求看某几条时，红线仍要全部过一遍；范围外发现红线或必改问题也要指出。

## 批注要求

每个问题一条批注，挂在问题所在的原文上；合同缺失的条款挂在最相关的条款或标题上。同一问题出现在多处的只批注一次，并在批注中写明其他位置。

**等级**

| 等级 | 含义 |
|---|---|
| 红线 | 命中 `redlines.md`，必须修改或走特批 |
| 必改 | 可能导致重大损失、违法违规或关键条款不可执行 |
| 建议改 | 风险可控，但会增加争议、成本或执行难度 |
| 需核实 | 结论取决于缺失事实、现行政策、内部资料或对方确认 |
| 提示 | 低风险文本问题或谈判提示 |

**内容格式**

```
【必改｜付款】尾款以甲方竣工和审计为前提，均由甲方控制且无最迟期限，回款可能无限期拖延。
依据：RL-06；ROLE-S-01
建议：改为验收合格且收到发票后 30 日内付清，审计结果仅用于多退少补。
建议措辞：甲方应于货物验收合格且收到乙方发票之日起30日内支付剩余货款，审计结果不影响付款期限。
```

- 问题写清对我方的具体影响，不写“建议完善”“存在风险”这类空话。
- 依据写清单编号、法规或查询结果（站点 + 日期）。无可靠依据的标【需核实】，不臆造。
- 英文合同的建议措辞用英文写，批注说明用中文。
- 重大法律、税务、监管判断提示交由相应法域专业人士确认。
- 爬架清单（PJ-xx）为补充编制，引用时表述为“行业通行做法”，不表述为“公司规定”。

**总评**

在合同标题处加一条总评：

```
【总评】需修改后签（可签 / 需修改后签 / 有重大问题不建议签）
评审立场：<具体签约主体>（<角色>）；依据：<主体识别依据>
合同类型：<类型>；适用清单：<红线、GEN、ROLE-S、EXP、LMS ……>
问题统计：红线 X｜必改 X｜建议改 X｜需核实 X｜提示 X
主要问题：<最多 5 条，附编号>
待比对事项：<〔比对〕项及需要的内部资料>
外贸合规：<核实结果、未完成现场核验的事项；纯境内合同写“不适用”及理由>
```

总体判定看最高风险，不因问题数量多就判“不建议签”。
