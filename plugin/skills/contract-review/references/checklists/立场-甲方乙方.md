# 立场清单：我方是甲方还是乙方

同一条款对买卖双方的利弊相反。先确定志特（GETO）关联主体在合同中的角色，再用对应一节补充审查。

| 合同叫法 | 我方为“供给方” → 用第一节 | 我方为“需求方” → 用第二节 |
|---|---|---|
| 买卖/销售 | 卖方 Seller | 买方 Buyer |
| 租赁 | 出租方 Lessor | 承租方 Lessee |
| 施工/分包/服务 | 乙方、承包方、服务方 | 甲方、发包方、委托方 |
| 采购 | 供应商 | 采购方 |

> 注意：“甲方/乙方”只是称谓，有的合同把卖方写成甲方。一律按实际权利义务判断，不按称谓判断。
> 带〔补充〕的条目依行业惯例补充，不来自原评审资料，业务部门可按需删改。
> 志特常见角色：铝模/爬架销售与租赁中为卖方/出租方/乙方；向供应商采购原材料、配件、外购贸易品时为买方/甲方。

## 第一节　我方为卖方 / 出租方 / 乙方

关注回款、责任封顶和对方单方控制的节点。

- **ROLE-S-01 付款节点**：避免使用只有对方知晓或控制的节点（“工程整体竣工”“甲方审计部门审计后”“业主付款后”）；确需使用时加最迟付款期限。（RL-06）
- **ROLE-S-02 结算拖延**：可深入约定“收到我方结算资料后 X 日内书面回复，逾期视为认可”，避免结算长期拖延。
- **ROLE-S-03 背靠背**：面对中小企业客户一般不接受背靠背；确需接受的，补对方积极催收义务和我方催收知情权。（RL-08，效力判断见 GEN-27）
- **ROLE-S-04 对方违约金**：对方逾期付款违约金不应设上限或留空【】。（RL-16）
- **ROLE-S-05 我方责任**〔补充〕：我方违约金/赔偿争取设合理上限，排除间接损失；逾期交货罚款须有除外条件。（RL-17）
- **ROLE-S-06 质保金**：比例不超过 3%，期限不超过 2 年，写明到期无息返还时点。（RL-14）
- **ROLE-S-07 债权**：不得约定禁止债权转让/禁止提供担保（影响保理和中信保）。（RL-19）
- **ROLE-S-08 结算方式**：不接受工抵房、以物抵债。（RL-09）
- **ROLE-S-09 所有权保留**〔补充〕：付清全款前所有权归我方；租赁物所有权始终归我方，承租方不得抵押、转租、出售。
- **ROLE-S-10 暂停履行**〔补充〕：对方逾期付款时，我方有权暂停发货/停止技术服务、顺延交期，不承担违约责任。
- **ROLE-S-11 验收视同**：约定验收期限，逾期未验收或未提书面异议视为验收合格。
- **ROLE-S-12 担保**〔补充〕：对资信一般的客户争取押金、预付款、连带责任保证或母公司担保。
- **ROLE-S-13 管辖**〔补充〕：争取我方所在地法院或我方熟悉的仲裁机构。

## 第二节　我方为买方 / 承租方 / 甲方

关注交付质量、索赔范围和发票合规。

- **ROLE-B-01 结算回复**：不要约定“收到结算资料后 X 日内回复，逾期视为认可”。（RL-33）
- **ROLE-B-02 背靠背**：我方（如江西集团）属大型企业时，与中小企业供应商约定“建设单位不付款则不付款”无效，不要写。（RL-32）
- **ROLE-B-03 间接损失**：把间接损失纳入索赔范围；签约沟通时写明货物用途、违约将造成的损失（证明可预见性）。
- **ROLE-B-04 发票**：开具不合规发票导致我方无法抵扣、被处罚的，供方赔偿全部损失。（RL-34）
- **ROLE-B-05 付款凭票**：进度款、尾款凭合规发票支付；预付款可先款后票。
- **ROLE-B-06 质量与验收**〔补充〕：质量标准具体到国标/行标与参数；样品封存；我方有合理检验期，隐蔽瑕疵可在质保期内主张。
- **ROLE-B-07 质保金**〔补充〕：可在法定上限内预留质保金，写明扣除条件。
- **ROLE-B-08 逾期交货**〔补充〕：供方逾期交货违约金明确，并保留解除合同和另行采购的权利，差价由供方承担。
- **ROLE-B-09 价格稳定**〔补充〕：固定价或调价有上限，避免供方单方涨价。
- **ROLE-B-10 资质与资信**：供方营业执照、资质、税务信用、涉诉情况查询（GEN-02/GEN-03）。
- **ROLE-B-11 工抵房**：我方作为买方时，能否对供应商约定以工抵房结算，原资料留有疑问、尚无结论。遇到时批注【需核实】，交法务确认。
