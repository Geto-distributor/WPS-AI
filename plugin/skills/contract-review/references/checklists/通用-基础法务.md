# 通用清单：基础法务（所有合同必过）

适用于所有合同，不分内贸外贸、不分我方是买方还是卖方。立场差异见 `立场-甲方乙方.md`。
标 〔内贸〕 的条目主要针对中国境内合同；外贸合同按对应法域理解。

> 来源：《买卖合同主要关注要点0910》《销售合同审阅建议》，以及原 skill 的“文本与文件质量”维度。

## 一、签约主体与资信

- **GEN-01 主体名称**：企业名称与营业执照全称一致。法人主体写明统一社会信用代码（境外为注册号）、住所地、联系方式；自然人写明姓名、身份证号、住所地。
- **GEN-02 履约能力**〔需外部查询〕：通过国家企业信用信息公示系统、中国执行信息公开网、企查查/天眼查等查询涉诉、失信、经营异常、注册资本实缴情况。查不到或未查时批注“需核实”，不臆测。
- **GEN-03 税务信用**〔内贸〕〔需外部查询〕：电子税务局 / 信用中国核查有无欠缴增值税、虚开发票处罚、走逃失联记录、纳税信用等级。
- **GEN-04 境外主体资信**：涉外合同按标的金额决定是否通过当地商事机构调查；金额较小的不强制付费调查，但应提示。
- **GEN-05 联系人与送达**：约定对接人、联系方式、送达地址、指定邮箱，以供追款和诉讼文件送达。未约定的，追款/诉讼可能要公告送达，拖长程序、增加费用。（缺失即命中 RL-24）

## 二、标的物

- **GEN-06 标的描述**：名称、品牌、规格、型号、生产厂家、产地写清楚。
- **GEN-07 计量单位**：明确数量与计量单位。建材计量方式多（重量、面积、体积、件数），避免“包”“车”“箱”“批”等未约定规格的含糊单位。
- **GEN-08 质量标准**：写明国标/行标及具体技术参数；检验、验收、工程标准、材料质量标准要具体。预制件要写明钢筋、混凝土等的标号、品牌、产地。
- **GEN-09 非标品与样品**：非标价产品必须有明确详细的图纸，或双方确认样品，不能含糊表述。
- **GEN-10 附随义务**：涉及指导、安装、运输等附随义务的必须写明；收费的要写收费标准。

## 三、价款与结算

- **GEN-11 含税与否**：注明含税/不含税单价、总价。〔内贸〕分开显示合同总金额、税率、不含税金额、税额。
- **GEN-12 外币与汇率**：外币计价的，约定汇率变动的处理原则。
- **GEN-13 价外费用**（财务要求）：写明运费、安装费等价外费用是否计入总价款，列明额外收费标准，避免隐性成本。
- **GEN-14 浮动价**（财务要求）：写明调价触发条件、测算标准和上限，禁止无上限定价。（命中 RL-02）
- **GEN-15 金额一致**（财务要求）：总金额、单价、计量单位、大小写完全一致；禁用“市场价另行协商”等模糊计价。（命中 RL-03/RL-04）
- **GEN-16 原材料价格波动**：预制件等受原材料影响大的产品，约定原材料涨跌时的调价规则；集团禁止预制件固定单价。（命中 RL-01）
- **GEN-17 结算时点**：写明办理结算的时点，如完工/退场后多少天。尾款常按结算后确定付款时点，结算时点不明会导致长期拖延。

## 四、付款

- **GEN-18 付款节点**：写明预付款、发货款、验收款、质保金各节点；收款账户须为合同主体或约定账户，避免现金支付无凭证。
- **GEN-19 付款期限**：写明验收合格且收票后多少个工作日内付款，禁用无限期付款表述。（命中 RL-07）
- **GEN-20 先款后票**：预付款可约定先款后票；进度款、尾款原则上凭合规发票支付。

## 五、发票〔内贸为主〕

- **GEN-21 发票类型与时间**：约定发票类型（增值税专用/普通）、税率、开票时间节点。
- **GEN-22 不合规发票责任**：合作方开具的发票不符合税务规范，导致我方无法抵扣、被处罚或其他损失的，应赔偿全部损失（补缴税款、滞纳金、罚款、维权费用及其他直接/间接损失）。我方为收票方时缺失即命中 RL-34。
- **GEN-23 三流一致**：收款方、合同签订方、开票方一致；付款方、交付主体不一致的，留存全套合规委托资料。（命中 RL-10）

## 六、交货、验收与风险转移

- **GEN-24 交货**：交货时间（具体日期或触发条件）、地点、运输方式及运费承担方。
- **GEN-25 所有权与风险**：分别约定所有权转移时点和毁损灭失风险转移时点。
- **GEN-26 验收与异议**：指定有权签收人/确认人；约定验收标准、方法、质量与数量验收期限、异议期限，以及逾期未提异议视为验收合格。
- **GEN-27 背靠背付款**：一般不约定“背靠背”。确需约定的，同时约定对方负有积极催收义务、我方享有催收知情权。效力判断：
  1. 大型企业（如江西集团）与中小企业供应商约定“建设单位不付款则不付款”——无效；
  2. 我方为中小企业，与国企/大型企业签此类条款——无效，可以不禁止；
  3. 我方大型企业与客户签此类条款——有效，尽量规避；
  4. 中小企业之间——可能有效，建议禁止签。
  依据需核实现行《保障中小企业款项支付条例》及最高法相关批复。
- **GEN-28 质量保证金**：保证金总预留比例不高于结算总额的 3%；质保期一般 1 年，最长不超过 2 年。（命中 RL-14）

## 七、违约责任与担保

- **GEN-29 违约情形**：分别约定逾期交货、逾期付款、质量不合格等情形的责任。
- **GEN-30 违约金计算**：写明计算方式（如逾期金额日万分之二），利率写明是年/月/日标准，以及参照贷款利率还是存款利率；过高可能被调整。
- **GEN-31 违约金上限**：关注违约金是否设上限（如“上限为【】”）。原资料：“如果我方为供货方应避免此类条款约定”——即对方违约金被封顶对我方不利。（命中 RL-16）
- **GEN-32 惩罚性违约金**：一般不约定惩罚性违约金。我方为采购方时，建议把间接损失纳入索赔范围，并在签约沟通中写明货物用途和违约可能造成的损失（为可预见性留证据）。
- **GEN-33 担保**：保证担保写明保证人身份（自然人附身份证）及“连带责任保证”；抵押须办理登记。（命中 RL-18）
- **GEN-34 债权转让**：一般不要约定禁止债权转让或禁止提供担保。（命中 RL-19）
- **GEN-35 工抵房**：一般不要提前约定“工抵房”作为结算方式。（命中 RL-09）

## 八、争议解决与送达

- **GEN-36 法院管辖**：管辖法院须与争议有实际联系（被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地），一般应为买方、卖方、履行地、签约地之一；不得违反级别管辖和专属管辖；明确到区/县一级，不要只写到市。（命中 RL-21）
- **GEN-37 签订地**：约定合同签订地管辖的，必须写明签订地。（命中 RL-22）
- **GEN-38 仲裁机构**：仲裁机构名称具体且唯一；涉外仲裁写明仲裁地、机构、规则、语言和仲裁费用承担。（命中 RL-23）

## 九、不可抗力、生效与签署

- **GEN-39 不可抗力**：写明不可抗力范围和处理方法（通知、证明、延期/解除）。
- **GEN-40 生效与份数**：合同生效方式、一式几份、中英文版以哪种语言优先、指定邮箱。
- **GEN-41 电子签**：电子签须指定双方授权电子版合同的邮箱地址。

## 十、文本与文件质量

- **GEN-42 附件齐全**：正文、附件、清单、图纸、技术文件齐全，引用的附件确实存在。
- **GEN-43 前后一致**：名称、定义、买方/卖方称谓、金额、币种、日期、期限、编号、交叉引用前后一致。
- **GEN-44 无歧义无空白**：没有歧义、冲突、悬空指代、空白项、未替换的占位符或版本混用。
- **GEN-45 双语一致**：中英文版全部翻译到位，内容一致，语言优先条款明确。
- **GEN-46 格式**：条款序号连续、无拼写错误、字体一致、页眉页脚与页码正确。
- **GEN-47 可操作性**：权利义务、条件、例外、程序与后果能够实际操作。
