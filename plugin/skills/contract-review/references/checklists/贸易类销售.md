# 类型清单：贸易类销售

外购产品（塑料模板、雾炮机、钢管、高压类设备等非自产品）转售给海外客户的合同特有条目。
同时必过：`通用-基础法务.md`、`通用-出口与国际业务.md`、`立场-甲方乙方.md`、`../trade-compliance-notes.md`。

> 来源：《2025年合同评审及系统录入消项表》贸易类销售表。

## 一、评审前

- **TRD-01**〔比对〕确认报价单已经总监核对；确认供货地。
- **TRD-02** 确认产品可以出口（命中则 RL-25/RL-26）：
  1. 雾炮机和高压类设备出口到台湾、越南、菲律宾、柬埔寨、老挝、缅甸、泰国、马来西亚、文莱、印度尼西亚、日本、韩国须谨慎；
  2. 明令禁止出口给终端用户为军警及海上执法部门等机构；
  3. 往台湾出口的高压类、钢管类物资要做好前期调查，由湖南志特向商务厅报备，按审核结果决定能否出口。
- **TRD-03** 确认是否侵犯专利权。

## 二、品名与知识产权

- **TRD-04** 英文品名有无特殊显示要求；塑料模板固定用 “Hollow Plastic Building Formwork”。
- **TRD-05**〔比对〕开票品名能否报关、单位、HS CODE；复核 HS CODE 退税率与供应商开票税率（退税按开票税率退）。
- **TRD-06** 确认产品品牌，是否在海关有知识产权备案。

## 三、数量

- **TRD-07** 暂定数量、按实际结算的条款；确认能否用中行收款。
- **TRD-08** 注明了重量的产品，写明公差范围。
- **TRD-09** 写明了柜量的产品，确认柜量经过核算；数量较小时确认运费和出运方式。

## 四、价格

- **TRD-10** 计价方式便于结算。
- **TRD-11**〔比对〕与商务确认打包方式，打包成本已计入，评估货损风险。
- **TRD-12** 物权条款。
- **TRD-13** 差价率低于 8% 或预付款低于 10% 的，需总监及连总审批。（RL-05）

## 五、交货

- **TRD-14** 明确清关单据种类；特殊单据能否出具、费用是否已考虑。

## 六、特殊要求

- **TRD-15** 新产品/新国家有无特殊认证要求；预估认证费用和耗时。
- **TRD-16** 提醒销售与客户确认有无特殊单据、产品、打包要求；新产品确认目的港能否进口。

## 七、其他

- **TRD-17** 质保条款的期限、责任划分合理（〔补充〕外购产品要与供应商的质保背靠背衔接，避免我方对客户质保期长于供应商对我方的质保期）。
- **TRD-18** 风险条款、特殊条款逐条确认。
