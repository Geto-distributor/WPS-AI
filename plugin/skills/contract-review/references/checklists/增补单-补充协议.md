# 类型清单：增补单 / 补充协议

对已签合同的增补单、补充协议、变更协议。重点是与原合同衔接。
同时按原合同类型带上对应清单中与增补内容相关的条目（不必全量重过）。

> 来源：《2025年合同评审及系统录入消项表》增补单 补充协议表。

## 一、与原合同衔接

- **SUP-01** 页眉页脚、标题正确。
- **SUP-02** 卖方、买方称谓前后一致，且与原合同一致。
- **SUP-03** 增补单/补充协议编号正确。
- **SUP-04** 引用的原合同信息（名称、编号、签订日期）正确。
- **SUP-05** 签署信息前后一致，签署人与原合同一致。
- **SUP-06**〔补充〕写明本协议与原合同的关系：未变更部分继续有效，冲突时以本协议为准。

## 二、增补内容

- **SUP-07** 增补/补充内容描述完整、准确。
- **SUP-08** 复核增补产品数量、单位、单价、币种、总金额。
- **SUP-09** 写明数量为暂定数量。
- **SUP-10** 付款方式、节点、时间明确；付款时间尽量不用工作日，必须用时按中国工作日制。
- **SUP-11**〔比对〕付款条款符合客户评级评分制度（台湾、香港、马来西亚、新加坡客户）。
- **SUP-12** 增补货物的备货时间、运输条款。
- **SUP-13** 配件增补须确认报关 HS CODE：并入大货申报还是单独申报；单独申报时能否用当前合同签订抬头申报。
- **SUP-14**〔补充〕租赁项目的增补：租期、免费延长期、清洗费、回程运费是否随之调整。（暂出复进项目的增补按销售处理，见 LMZ-08）
