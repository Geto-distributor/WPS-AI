# 外贸合规常驻知识（建材建筑 / 铝模 出口审核）

供 contract-review 在审查跨境贸易条款时使用。核心原则：**具体税号、税率、退税率、关税、政策一律以"现场查询"为准，本文件只给方法、要点与"该查什么"。凡本文件给出的编码/数字都是候选或历史值，务必到对应站点现查确认；搜索引擎摘要、第三方转载或聚合结果不能替代指定站点查询。未实际取得指定站点返回结果时，不得表述为"已核实"，应标记"未完成现场核验"或"需核实"。**

政策会变——本文件里凡带"⚠️"的，都是近期有过变动或高发争议、必须现查的点。

---

## 一、四个查询站点怎么用

### 1. 世界各国海关网 — https://www.waimaoribao.com/baike/65158.html
- **用途**：这是一个**各国海关官网的导航页**。按合同的**进口国/目的国**点进对应国家的海关官网，查该国的**进口关税、清关流程、报关报检、禁限类目、优惠税率适用条件**。
- **怎么用**：先从合同确定目的国（如马来西亚），进该国海关（马来西亚是 **JKDM / Royal Malaysian Customs**），用商品 HS 编码查进口关税（Import Duty）与销售税（SST）。
- **要点**：目的国税费（关税+SST/VAT）**由谁承担**要和合同 Incoterms/税费条款对齐；很多国家对钢铝制品有**反倾销/保障措施**，需确认铝模是否被波及。

### 2. 申报要素查询 — http://hscode.net/IntegrateQueries/QueryYS
- **用途**：查商品的 **HS 编码归类**与**报关"申报要素"**（即报关单上该商品必须申报的规格字段）。
- **怎么用**：输入商品名（如"铝合金模板""铝模板""爬架"）或候选 HS 编码，读出**归类**与**申报要素清单**（通常含：品名、材质/成分、用途、品牌、型号、规格、单价等）。
- **要点**：合同里的**品名/材质/规格描述要能支撑申报要素**——如申报要素要"铝合金牌号（如 6061-T6）、用途、规格"，合同标的描述最好就写清这些，避免报关时对不上。

### 3. 出口税政策 — https://hd.chinatax.gov.cn/nszx2023/cktslcx2023.html
- **用途**：查**出口退（免）税政策**——按 HS 编码查该商品当前的**出口退税率**、是否可退、是否属征税/禁止出口。
- **怎么用**：输入 HS 编码，读当前退税率与政策。
- ⚠️ **重点·政策近期有重大变动**：**中国已取消部分铝、铜制品的出口退税**（2024 年底起，原 13% 退税被取消的品类）。**铝制品（含很多 76xx 税号）很可能受影响**——**绝不能沿用旧的"13% 退税"假设**，必须现查当前 HS 编码的实际退税率。这直接影响合同里的**报价含退税与否、价格调整、税负承担**条款。

### 4. 品牌查询 — http://202.127.48.145:8888/zscq/search/jsp/vBrandSearchIndex.jsp
- **用途**：查合同涉及的**品牌/商标**权属与状态（用于报关"申报要素"里的品牌字段、以及避免侵权）。
- **怎么用**：输入品牌名查商标注册主体、状态。
- **要点**：出口货物报关要如实申报品牌；若合同货物带商标，确认**商标权属清晰、我方有权使用/授权**，避免侵权或报关品牌与实际不符。

> 这些是国内政务/查询站（hscode.net、chinatax、品牌查询为 IP 站）。运行环境**能不能连上、要不要验证码/登录**不一定；连不上时**不要硬编结果**，在批注里标【需核实】并说明要查什么。

## 二、铝模 / 爬架的 HS 归类（候选，务必到 hscode.net 现查核实）

以下是**候选归类**，用于提示方向，**最终以申报要素查询结果为准**：

- **铝合金模板（面板/墙柱/楼面模板等，铝结构件）** → 大概率 **7610.90**（铝制结构及部件，"结构"税目明确含"模板/shuttering"类）。
- **配套支撑（钢制立杆/顶托等）** → 可能落 **7308.xx**（钢铁结构及部件，含 shuttering）；铝制支撑则归铝。
- **对拉螺杆、销钉楔片、山型卡等连接件** → 视材质与功能，可能落**紧固件（钢 7318）**或对应金属制品税目。
- **爬架 / 附着式升降脚手架** → 视结构与材质，可能落钢/铝结构件税目。

**公司评审惯例（来自《2025年合同评审消项表》铝模销售表）**：菲律宾、越南用 7610900；沙特需单次确认按 848060 还是 761090；其他市场常规用 84806000。
惯例与上面的候选归类不一致（8480.60 为“矿物材料用型模”方向）。评审时不在两者之间自行裁定：合同写了 HS 编码的，按惯例核对并提醒商务确认；与现查结果冲突的批注【需核实】。

> 一份合同里往往**多税号**（模板、支撑、配件各不同）——审核时提醒：报关归类与合同标的清单要能对上，避免"一个 HS 编码报全部"导致归类错误。

## 三、出口退税 —— 审核要点（⚠️ 时效敏感）

- **必现查**：用 chinatax 站按每个 HS 编码查**当前退税率**；铝制品退税政策**近期已调整（取消部分铝制品出口退税）**，旧资料不可信。
- **对合同的影响**（审核时逐条看）：
  - 报价**是否声明"含/不含出口退税"**；若原报价基于"能退 13%"而政策已取消，**成本上升由谁承担**要有价格调整或分担条款。
  - **税负与价格调整条款**：政策变动（退税取消、关税调整）时的价格重议机制。
  - 若属**征税或禁止出口**类目，合同可行性直接受影响，须醒目提示。

## 四、目的国海关要点（以马来西亚为主，东南亚通用）

马来西亚（志特常见目的国，如柔佛新山项目）：
- **海关**：JKDM（Royal Malaysian Customs）。查铝模相关税号的**进口关税（Import Duty）+ 销售税（SST）**。
- **税负归属**：进口关税、SST、清关费**由谁承担**要和合同 Incoterms/税费条款一致（常见承租/采购方承担）。
- ⚠️ **反倾销/保障措施**：马来西亚等国对**中国钢铝制品**时有反倾销税，**务必现查铝模对应税号是否被波及**——若被波及，进口成本大增，直接影响成交与税负条款。
- **准证/标准**：部分建材需符合当地标准或准证；高空作业设备（爬架）可能涉安全认证。

## 五、原产地与优惠关税（ACFTA / Form E）

- 中国—东盟自贸协定（**ACFTA**）下，符合原产地规则的货物凭**原产地证 Form E** 可享**优惠（常为更低甚至 0）进口关税**。
- **审核要点**：合同**有没有约定我方提供 Form E**、由谁办理、费用与时限；用了优惠税率的，进口方省的关税是否已体现在价格里。**Form E 缺失或原产地规则不满足 → 优惠税率拿不到、进口成本上升**，这类风险要在批注里点出。
- 具体优惠税率**以目的国海关 + 现行 ACFTA 税率表为准**，现查。

## 六、跨境付款、外汇、税、发票（合同里逐条核）

- **Incoterms**：FOB / CIF / DAP 等——**风险与费用（海运、保险、清关、目的国税费）划分点**是否清晰、与"运费/风险转移/税负承担"条款一致。
- **币种与外汇**：结算币种、汇率基准与波动承担；跨境收款路径（T/T / 信用证）是否合规、是否受外汇管制影响。
- **目的国间接税**：马来西亚 **SST**、报价含不含；**发票合规**（马来西亚 **LHDN e-Invoice** 已强制，确认开票主体与格式满足）。
- **预扣税（WHT）**：跨境服务/租赁付款可能被目的国预扣税，**由谁承担**要写清。
- **原产地证/单证**：装箱单、发票、提单、Form E、质检/合格证等单证责任与时限。

## 七、外贸合规审查清单（对着合同逐条过）

- [ ] 标的品名/材质/规格描述能支撑**报关申报要素**（材质牌号、用途、规格、品牌）。
- [ ] 每类货物的 **HS 归类**已现查、合同清单能对上（不是一个税号报全部）。
- [ ] **出口退税率**已现查（⚠️ 铝制品政策近期变动），报价含退税与否明确、变动有价格调整条款。
- [ ] **目的国进口关税 + SST/VAT** 已现查，税负归属与 Incoterms 一致；查**反倾销/保障措施**是否波及。
- [ ] **ACFTA/Form E** 优惠适用、办理责任与费用、缺失风险。
- [ ] **品牌/商标**权属清晰、报关品牌如实、无侵权。
- [ ] Incoterms、原产地、跨境付款/外汇、SST、WHT、e-Invoice、单证责任齐备且一致。

## 八、常见坑（优先批注）

- **沿用旧退税假设**：报价按"铝材能退 13%"算，但政策已取消 → 成本黑洞、无价格调整条款。⚠️ 最高发。
- **税负归属含糊**：目的国关税/SST/清关费"由谁承担"没写清或与 Incoterms 矛盾。
- **反倾销税漏查**：进口国对中国钢铝有反倾销税，进口成本远超预期。
- **HS 归类粗糙**：一个税号报全部货物，报关被查、归类补税。
- **Form E 责任缺失**：想享 ACFTA 优惠却没约定谁出原产地证，优惠落空。
- **申报要素对不上**：合同标的描述缺材质牌号/用途/品牌，报关卡壳、货物滞港。
